# Melody School Website

A responsive school landing page built with HTML, Tailwind CSS (CDN), custom CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `melody-school-website` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension and click **Go Live**.

## Project structure
```text
melody-school-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
└── README.md
```

## Included
- Responsive desktop, tablet and mobile layouts
- Tailwind CSS utility classes
- Mobile slide-in sidebar with overlay and close controls
- Animated hero, floating cards and scroll reveal effects
- About, programs, campus, testimonials, admission and contact sections
- Contact form front-end demo feedback

## Customize
- Edit content and sections in `index.html`.
- Change colors, animation and responsive styling in `css/style.css`.
- Update menu, scroll effects and form behavior in `js/main.js`.
- Replace the Unsplash image URLs with your own school photos.

## Important
Tailwind CSS and Google Fonts are loaded from CDNs, so an internet connection is required for those resources. The contact form is a front-end demo only; connect it to your Laravel backend to save and receive messages.
